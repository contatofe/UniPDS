# Módulo 4 - Aula 2

## COMO FUNCIONAM SISTEMAS DE RECOMENDAÇÃO

Estamos simulando e treinando uma rede neural em tensorflow.js que treina com os dados direto no navegador para fazer um sistema de recomendação inicial. Passamos pelas etapas de normalização dos dados manualmente, antes de treinar de fato. Posteriormente foi criada uma rede neural para fazer as predições de cada cliente, de acordo com as compras anteriores e a idade inputada nos dados.
